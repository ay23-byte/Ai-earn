# Requirements and traceability

Status values here are `VERIFIED`, `NOT_IMPLEMENTED`, or `UNVERIFIED`; phase statuses are tracked separately. These are grouped requirements, not permission to omit detailed acceptance criteria. Current product scope is a local-first workflow application with an authenticated loopback HTTP workspace API and persistent SQLite data. It is not a hosted SaaS or live payment service. Older row notes are retained only where still accurate; the current implementation baseline is schema v30. Human Windows, accessibility, restore, and independent security acceptance remain pending.

Expand rows into narrower stable IDs when implementation needs more detail, preserving the parent IDs and original acceptance criteria. No proposed feature should be represented as implemented because it appears in this matrix.
